# 长上下文计费 / Long-context pricing

## 中文

`启用长上下文计费.command` 保存用户提供的 gpt-6.1-sol 费率，备份原配置，保持 App 打开并重启空闲 Bridge；不刷机、不清计数、不导入账单。不修改其他模型。待处理审批必须先完成。此入口使用当前 Wi-Fi 配对，完成后需保持终端打开。

| 折后 USD / 百万 Token | 输入 ≤272000 | 输入 >272000 |
|---|---:|---:|
| 非缓存输入 | 0.36 | 0.72 |
| 缓存读取 | 0.018 | 0.036 |
| 缓存写入 | 0.45 | 0.90 |
| 输出（含推理） | 1.80 | 2.70 |

以上已乘 0.18；不再重复乘倍率。截图及账单支持这组自定义服务商费率，不为其他服务商自动套用。长档阈值取单次请求输入 Token（含缓存），严格大于 272000，不含输出；超过后整笔请求采用长档，非仅超出部分。不是累计整轮或整天达到阈值就涨价。上下文容量、上下文填充量和计费累计也不是同一概念。

费率文件在 `private/token_rates.json`，模型可选 `long_context`，字段为 `above_input_tokens`、`input`、`cached_input`、`output`、`cache_write`。GUI 可配置开关、阈值和折后价格；旧单档配置继续有效，无效长档不会静默退回普通档。

数值账本增加逐请求记录，保留现有 Token 去重与累计来源核对。普通 App 事件仅在确定为单笔增量时记录价格边界；缺失中间事件不得当成一次长请求。完成记录回放可为旧账本补回边界，不再重复计 Token；后台补充仍与迟到本机记录互斥。旧历史缺少完整请求边界时费用为未知，不能把累计量误套长档。清零只清本机计数及本机价格边界，保留原始重放基线。

CSV 对账按每笔请求计算，后台 Billed Cost 不再乘倍率。差异需考虑后台逐笔舍入。账单原文件及任何真实明细均不放入公开源码；回归测试使用合成数值。

依据：用户提供的服务商价格截图及私有 CSV；[OpenAI 模型文档](https://developers.openai.com/api/docs/models/gpt-6.1-sol)用于交叉核对，第三方最终计费仍以其账单为准。

## English

The launcher backs up and applies the user-provided Sol card, then restarts only an idle project Bridge while keeping the App open. It does not flash firmware, reset counters, import billing rows or change other models. Pending approvals block restart; keep the terminal open afterward.

The table lists already-discounted USD per million tokens; never multiply by 0.18 again. The threshold is strictly greater than 272,000 input tokens per request, including cache and excluding output. The whole request uses the selected tier, not just excess tokens. Accumulated session/turn totals and model context capacity must never select a tier.

Optional per-model `long_context` configuration contains `above_input_tokens` and the same four price fields as the standard card. The local GUI supports this configuration. Flat-rate cards remain compatible; malformed tiers are rejected rather than silently underpriced.

Persistent numeric request records preserve pricing boundaries alongside existing token reconciliation. Replay upgrades old ledgers without recounting tokens. Missing event gaps are not invented request boundaries. Costs remain explicitly unavailable when complete per-request coverage cannot be recovered. Resets retain raw replay baselines. Provider supplements and late local completions remain mutually exclusive.

CSV reconciliation prices individual requests; exported Billed Cost already includes its discount. Per-row rounding may cause tiny differences. Actual exports remain private and public tests use synthetic fixtures.
