# 常见问题

简体中文（默认） · [English](10-QUICK-FAQ.en.md)

**设备在线，为什么没有审批？** 设备同步、Hooks 和 App relay 是不同链路。先检查 App 是否经已核对入口启动、原聊天是否已接入，以及请求是否属于支持类型。

**App 已运行，只重启 Bridge 能恢复吗？** 只有 App 已通过 relay 启动时才可接回。普通启动的 App 需保存工作、手动退出，再由唯一控制台启动。

**能使用第四个应用键或上下组合键吗？** 当前交互仅依赖三键。方向键共用 ADC 电阻梯，组合键不得作为必要操作。

**缺少模型、费率或请求边界时如何显示？** 明确报告未知或待确认，不猜模型、不用累计用量推断单次请求费率，也不以 0 替代缺失数据。CSV 推理字段的既有 0 值属于已记录的适配限制。

**输入、缓存、输出和推理如何求和？** API 输入包含缓存，输出包含推理。展示时拆成未缓存输入、缓存读、缓存写、可见输出和推理五个互斥分项，各累计一次。

**总 Token 超过阈值就采用长档吗？** 不采用总 Token 判档。按价格卡规定的单次输入（含缓存）阈值选择档位，再汇总各请求。内置阈值及价格为快照。

**Git 仓库是否包含完整恢复材料？** 不包含。配对、私钥、账本、Apple 图像、含图固件和设备备份只保留本机；工具链也需另行配置。

**迁移后能直接使用旧缓存吗？** 不应直接复制旧 venv、绝对路径 .pth 或 CMake 缓存。Hooks 路径和 IPC endpoint 随项目路径变化，需按迁移流程核对并保留回退材料。

**确认提醒已读是否等于允许或回复？** 否。阅读提醒、回答问题、提交授权和工具执行是不同事件。

**源码版本是否证明设备已更新或补丁已加载？** 否。源码、镜像、最近运行日志、实际加载版本和实机验收须分别记录。

**Windows 固件维护仍不可用吗？** 已接入。菜单 7 提供构建、镜像校验、安全 USB 升级及独立刷写环境准备；私有素材已恢复，用户已确认修复后的升级及基本目视检查完成。完整功能、Windows 10 及长期稳定性仍须单独记录。

**英文 Markdown 是否代表控制台和设备已改为英文？** 不代表。第一阶段只做文档；第二阶段现已提供独立中文/英文 `.command` / `.cmd` 控制台及英文子工具、费率窗口和 PC 日志。第三阶段 0.2.14 现已提供按安装入口构建的中英文设备固件；之后 PC 控制台语言不改设备已安装语言。第三方原始输出及用户数据也不替换；见 [设备语言](13-DEVICE-LANGUAGES.md)。见 [PC 端语言说明](12-HOST-LANGUAGES.md)。
