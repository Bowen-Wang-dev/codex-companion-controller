# 新 Agent 常见误解

**为什么设备有额度而审批不来？** 账户用量同步、Hook提醒、App relay审批是不同链路。先查状态，不反复刷机。

**为什么看到Wi-Fi在线却不能Allow？** 可能只是Bridge连通，App不是从适配入口启动、未加载原聊天、请求语义未支持，或详情/期限不全；不等于用户不会按键。

**能用第四个电源键吗？** 现有应用不依赖它；三键共用ADC，组合键也不能当必选方案。

**为什么有Unknown/缺费率？** 数据未提供、当前模型不明、字段来源不完整或缺请求边界时应明确未知，不填0、不猜模型。

**输入+缓存/输出+推理能相加吗？** API输入已含缓存，输出已含推理。仅拆成互斥类别之后才能求和。

**总Token过272K就贵吗？** 不是。是单次请求输入含缓存>272K后整笔选长档，之后多请求累计。

**从GitHub拉代码就能原样刷吗？** 不行。图片、配对、私钥、账本、含图固件和备份不在Git；工具链也需本机配置。

**迁移只是把文件夹改名吗？** 不止。旧venv/.pth/CMake缓存、Hooks绝对路径和私有IPC hash都会受路径影响；保留旧项目做回退。

**read-only approval通知确认已读能替我回答问题吗？** 不能。用户输入/操作提醒与Allow/Deny是不同请求。
