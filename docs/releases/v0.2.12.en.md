## Changes in this version

- The native approval card in the current original ChatGPT / Codex desktop App chat and AI Passport show the same request. Preserve App, account and chat without a new session or independent Companion / Tk approval window.
- Desktop `PermissionRequest` and permission `PreToolUse` Hooks return empty results instead of blocking native cards. Empty is not automatic approval; the following actual native request reaches the device through the stdio relay.
- First valid App / device answer wins and clears the other. Device Allow still requires final-page selection, second confirmation and matching real submitted receipt.
- Holding confirm on device details sends a request-bound Mac handoff, activating the already running exact-version / digest-verified App without clicking approval buttons.
- Fixed ordinary Mac Terminal updates failing without bare `python`: separate Bridge / flash interpreters and check esptool 4.x before Bridge stop.
- Bridge diagnostic revision `0.2.12-native-app`, `approval_ui=native_app`, firmware `0.2.12`. Old standalone UI entry remains only a compatibility no-op; do not restore that design.

## Upgrade procedure at that release

The daily entry was `controller/Codex Companion 控制台.command`:

```bash
bash "/你的工程路径/controller/Codex Companion 控制台.command"
```

Replace the placeholder directory with the real project path.

- Already on 0.2.12: retain App / original chat, choose 2 → 2 safe Bridge restart and keep Terminal running. Pending approvals prevent restart; no repeat flash or pairing.
- Older firmware: prepare / validate local 0.2.12 image, connect USB and choose 7. The entry tests and checks App / image / flash interpreter, asks confirmation, stops Bridge, reads dual backups, validates live partitions, writes only factory, verifies readback and reconnects Bridge to App.
- Without IDF in ordinary Terminal, set `CONTROLLER_FLASH_PYTHON` in ignored `controller/private/local-env.sh` to an existing absolute Python with esptool 4.x. Bridge still uses `CONTROLLER_BRIDGE_PYTHON`; do not assume one environment satisfies both.
- GitHub source excludes Apple images / artwork firmware and local recovery dependencies. It is not a ready-to-flash complete device recovery package. Never use generic IDF flash output or whole-chip erase.
