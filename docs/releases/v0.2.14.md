# v0.2.14：安装入口决定设备语言

简体中文（默认） · [English](v0.2.14.en.md)

维护日期：2026-11-03（Australia/Sydney）。固件源码 `0.2.14`，Bridge `0.2.14-native-app`。本阶段完成源码和本地中英文构建，不代用户刷写或重启真实服务；已有实机反馈仍对应此前版本。本文是版本记录，不代表创建新 Git 标签或公开发布含图固件。

## 使用规则

从英文 `Codex Companion Console.command` / `Codex Companion Console.cmd` 构建和安装，设备从开机起使用英文，离线及重启后仍为英文。从中文入口安装则为中文。之后选择另一种语言的 PC 控制台，不改变设备已安装的语言。Windows/macOS 菜单 7 均提供构建、校验与安全升级子菜单，详见[设备语言手册](../handoff/13-DEVICE-LANGUAGES.md)。

## 变更

- 固件增加编译语言及 126 条设备静态文案，覆盖开机/离线、六个页面、配对、审批阅读、二次确认、计量/清零和音频提示。默认中文；原版 Apple 表情保留。
- 新 hello 发送 `ui_language_protocol=1` 与 `ui_language`，Bridge 按设备语言生成系统标题、授权说明、事件、状态和真实回执。旧设备保持中文，同一 boot 中不接受改语言；不会在待审批期间换页语言。
- 只翻译明确标记的系统文字。原始命令、路径、原因、问题和未知字段值不翻译；完整分页、请求摘要、允许/拒绝结果、末页送达、二次确认与真实 submitted 回执规则不变。
- 编译参数由安装入口传递；manifest 从镜像中的唯一语言标记确认 `ui_language`。入口、manifest、镜像语言不一致时提前拒绝，不停止 Bridge、不写设备。Windows 与 macOS 共用语言检查，Mac 保留原安全维护流程。
- 英文标签使用既有 Montserrat，混合中文用户内容使用原字库；调整标题宽度及回执排版，修正较长中文回执的既有重叠。预览工具直接复用固件 `render()`、锁定 LVGL 和真实字体，硬件由桩代替，输出只留 private。

- 新 hello 的上行缓冲统一为有界 768 字节，避免语言字段加诊断计数超过旧 512 字节限制；最大帧回归通过，审批详情接收边界仍为 4096 字节。中英文离线 LVGL 预览共 40 屏，标签越界/重叠检查为 0。
